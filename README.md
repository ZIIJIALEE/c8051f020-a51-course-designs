# 基于 C8051F020 的 A51 汇编课程设计

本仓库收录两个基于 **Silicon Labs C8051F020 单片机**（8051 内核）、使用 **A51 汇编语言**（Keil µVision 开发环境）完成的课程设计：

| 项目 | 目录 | 功能 |
| ---- | ---- | ---- |
| 科学计算器 | [`calculator/`](calculator/) | 4×4 矩阵键盘输入，6 位数码管显示，支持加、减、乘、除（BCD 运算） |
| 交通信号灯 | [`traffic-light/`](traffic-light/) | 双路红绿灯 + 倒计时显示，键盘密码修改通行时长 |

## 硬件平台

- 单片机：Silicon Labs **C8051F020**（8051 内核）
- 开发环境：Keil µVision（A51 汇编器，需 `C8051F020.INC` 寄存器定义文件）
- 显示：6 位共阴极 7 段数码管（动态扫描）
- 输入：4×4 矩阵键盘

## 项目说明

### 1. 科学计算器（calculator/）

- **键盘扫描**：P1 口，P1.0~P1.3 接键盘 0~3 行，P1.4~P1.7 接键盘 0~3 列
- **数码管**：P2 位选码，P3 段选码
- **蜂鸣器**：P0.1；**独立按键**：P0.0
- **功能**：支持加、减、乘、除，BCD 运算（`DA A`），可连续计算
- **显示刷新**：定时器 0 中断实现动态扫描

### 2. 交通信号灯（traffic-light/）

- **两路红绿灯**：P0.2~P0.4（第一路 绿/黄/红），P0.5~P0.7（第二路 绿/黄/红）
- **倒计时显示**：P2 位选码，P3 段选码
- **密码保护**：通过矩阵键盘输入密码，验证后可修改通行时长
- **时序控制**：定时器 0 控制红绿灯时序，定时器 1 负责数码管显示扫描

## 编译与运行

1. 在 Keil µVision 中新建工程，器件选择 **C8051F020**。
2. 将对应目录下的 `.asm` 文件加入工程。
3. 确保 Silicon Labs 提供的 `C8051F020.INC` 寄存器定义文件在包含路径中。
4. 编译无误后，将生成的 HEX 文件烧录到开发板运行。
